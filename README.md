# API REST
Favor ejecutar
```
npm install
```
Después, crear el archivo .env, el cual debe contener estas variables de entorno:  


PUERTO  


LIMITE_FILAS  


BD_USUARIO  


BD_PASE  


BD_PUERTO (por defecto, debe tener el valor 9999)  


BD_BASE  


BD_ENLACE

debe tener el valor 

```mongodb+srv://$BD_USUARIO:$BD_PASE@$BD_SERVIDOR/$BD_BASE```
